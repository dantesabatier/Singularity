# Singularity

**Singularity** is a next-generation IDE designed to build web applications with the architectural rigor and elegance of the **Cocoa** ecosystem.

By bridging the gap between desktop-grade software engineering and web development, Singularity brings the full power of **Foundation** and **Core Data** to **PHP 8.3+**. It provides a robust, visual environment to design, manage, and maintain complex applications through a desktop experience powered by **Electron**.

## 🚀 The Vision

The goal of Singularity is to evolve web development into a structured engineering discipline. By leveraging faithful ports of Apple's core frameworks, Singularity allows developers to use the same sophisticated patterns and robust architectures found in native macOS and iOS development within the PHP ecosystem.

## ✨ Core Pillars

- **Visual Data Modeling**: A professional interface inspired by Xcode’s Data Model Inspector for designing complex application schemas.
- **Full Core Data Integration**: A complete persistence and object-graph management layer, featuring managed object contexts, advanced predicates, and sophisticated relationship handling.
- **Foundation Framework**: Built upon a comprehensive port of Foundation, providing the essential base layer for object life cycles, collection management, and observation patterns.
- **Reactive Architecture**: Native support for **Key-Value Observing (KVO)**, enabling deeply integrated and consistent business logic.
- **Code & Schema Automation**: Live SQL schema visualization and automatic generation of managed object subclasses to streamline development.

## 🛠 Tech Stack

- **Runtime**: [Electron](https://www.electronjs.org/) for a seamless cross-platform desktop experience.
- **Backend**: **PHP 8.3+** (leveraging modern language features like *Property Hooks*).
- **Frontend**: [Latte Templates](https://latte.nette.org/) for clean, secure, and compiled UI rendering.
- **Framework Core**: Powered by the `Sabatier\Foundation` and `Sabatier\CoreData` ecosystems.
